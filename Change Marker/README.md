# Change Marker

변경된 layer에 **만료일이 있는 Figma 코멘트**를 달아 두고, 만료일이 지나면 자동으로 지우는 플러그인.
개발자는 Dev Mode에서 코멘트로 "무엇이 언제 바뀌었는지"를 보고, 디자이너는 지우는 걸 잊어도 된다.

코멘트 본문 예:

```
🟥 9.21 변경사항 · 변경 ID: 13ctm0
```

- 앞의 색 사각형 이모지 = 그룹 색 (Figma 코멘트는 색을 가질 수 없어서 이모지로 표현)
- `9.21 변경사항` = 그룹 제목
- `변경 ID: 13ctm0` = 플러그인이 핀이 옮겨진 뒤에도 코멘트를 다시 찾기 위한 ID. label은 UI 언어를 따른다
  (`변경 ID:` / `Change ID:`). 예전 형식(`주석 ID:`, `#a7f3k2`, 날짜가 들어간 2줄 형식)도 인식한다.

## 핵심 개념

- **코멘트 그룹(주석 모음)**: 제목·색·만료일을 가진 묶음. 만료일은 코멘트 본문에 쓰지 않고 플러그인에만 저장하므로,
  날짜를 바꿔도 이미 단 코멘트의 글자가 틀려지지 않는다. "무기한"도 가능.
- **코멘트**: 그룹에 속한 개별 Figma 코멘트. 항상 단일 핀(영역 아님).

## 기능

| 화면 | 기능 |
|---|---|
| 목록 › 코멘트 모음 탭 | 그룹 카드(색, 코멘트 수, 만료 배지 — 임박하면 빨강). `+ 새 코멘트 모음` |
| 목록 › 코멘트 탭 | 파일의 모든 플러그인 코멘트 로그(frame·페이지·작성자·날짜). 클릭하면 해당 핀으로 이동(페이지 전환 포함), ✕로 개별 삭제 |
| 그룹 상세 | 코멘트 미리보기, **코멘트 추가**(현재 뷰 중앙에 핀), 만료일 변경, 그룹 삭제(2단계 확인, 소속 코멘트 전부 삭제), 그룹의 코멘트 목록 |
| 새 그룹 폼 | 제목, 8색 팔레트 + hex 입력, 삭제일 또는 무기한, 게시될 본문 미리보기 |
| 설정 | 개인 액세스 token, 파일 링크(자동 감지 실패 시) |
| 헤더 | 설정(⚙), 동기화(↻), 새 그룹, 언어 토글 |

## 동작 방식 (중요한 제약)

- **REST API 사용**: 코멘트는 Figma REST API로만 달 수 있고 플러그인 샌드박스에서는 호출할 수 없어,
  `src/api.js`가 UI iframe에서 호출한다. 그래서 처음 실행할 때 **개인 액세스 token**
  (Figma → Settings → Security → Personal access tokens, `file_comments` 읽기+쓰기)이 필요하다. token은 이 컴퓨터의 `clientStorage`에만 저장.
- **핀 위치**: 선택과 무관하게 **현재 뷰의 중앙**. 그 지점 아래의 frame에 붙여 frame과 함께 움직이게 하고,
  빈 캔버스면 좌표로 붙인다. 뷰는 플러그인이 열려 있는 동안 폴링하며, 게시 순간 다시 읽는다.
- **만료 처리는 플러그인을 열 때(또는 ↻) 실행된다.** 백그라운드 실행이 불가능하므로
  "10/01 삭제"는 "그 날짜 이후 처음 플러그인을 열 때 삭제"라는 뜻이다.
- **코멘트는 API로 수정할 수 없다.** 그룹 제목·색을 바꾸면 이후 코멘트에만 반영된다. 만료일은 본문에 없으므로 전체에 적용된다.
- **자기 코멘트만 삭제 가능.** 다른 사람 token으로 단 코멘트는 지울 수 없고, 몇 개를 못 지웠는지 알려 준다.
- **동기화**: 그룹(코멘트 id 포함)은 파일의 `figma.root` plugin data에 저장되고, 동기화 때마다 실제 코멘트와 맞춘다.
  - Figma에서 지우거나 해결(resolve)한 코멘트도 반영된다.
  - 핀을 드래그하면 Figma가 코멘트를 새 id로 교체하는데, 본문·ID 줄이 같은 코멘트를 찾아 다시 연결한다.
  - 그룹에 속하지 않은 플러그인 코멘트는 "남은 코멘트"로 표시되고 제거 버튼이 생긴다.
- **Figma에서 코멘트 본문을 직접 고치면 "해제"된다.** 플러그인이 더 이상 건드리지 않으며(만료·그룹 삭제 대상 아님),
  남은 코멘트로도 표시하지 않는다. 다음 동기화 때 몇 개가 해제됐는지 알려 준다. ID 줄을 바꾸거나 지워도 같다.
- 긴 API 호출 중에는 화면을 흐리게 하고 스피너를 띄워 중복 클릭을 막는다.

## 실행

```bash
npm run build
```

`src/`나 `../doc/design-system/`을 고친 뒤에만 필요하다 (`npm run watch`로 자동 빌드).
Figma 데스크톱 → Plugins → Development → Import plugin from manifest… → `manifest.json`.

## 언어

한국어(기본)/영어. 모든 화면의 최상단 행 오른쪽 끝 토글. UI 문자열은 `src/i18n.js`, 샌드박스 토스트는 `code.js`의 `L`.

## 파일

| 파일 | 역할 |
|---|---|
| `code.js` | 샌드박스: 저장, 핀 위치 계산, 핀으로 이동, 토스트 |
| `src/api.js` | Figma REST 클라이언트 (코멘트 목록/게시/삭제) |
| `src/ui.html`, `src/ui.js`, `src/ui.css` | UI 소스 (`ui.css`는 이 플러그인 전용 style만) |
| `src/i18n.js` | 한국어/영어 UI 문자열 |
| `build.js` | `src/` + 공유 디자인 시스템을 인라인해 `ui.html` 생성 |
| `ui.html` | **생성물** — 직접 수정 금지 |
| `archive/` | 이전 버전 보관: `rectangle-plugin/`(색 사각형 layer 방식), `widget-version/`(배지 위젯 방식) |
