# 다국어(한국어/영어) 규칙

모든 UI 플러그인은 한국어와 영어를 지원한다. **기본 언어는 한국어**이며, 사용자가 고른 언어는
`figma.clientStorage`에 저장되어 다음 실행 때 유지된다.

## 언어 토글 표준

- 위치: 최상단 행의 **오른쪽 끝** — `header .hactions`의 마지막, 하위 화면이면 `.navbar`의 마지막,
  탭 바가 최상단인 경우(Config Manager) 탭 바의 오른쪽 끝.
- 마크업: `.lang-toggle > .lang-btn[data-lang]`, 순서는 `한국어 | EN`, 선택된 쪽에 `.active`.
- 모든 화면(목록·상세·폼·설정)에서 보여야 한다.

## 한국어 문구의 용어 규칙

한국에서도 영어로 쓰는 용어는 한글로 음차하지 않고 **영문 그대로** 쓴다 (예: `컨피그` ✗ → `config` ✓).

| 구분 | 영문 유지 | 예 |
|---|---|---|
| 플러그인 전용 용어 | ✓ | config, preset, token, variant, slot, instance, Boolean, Live, ID |
| Figma 객체 이름 | ✓ | component, main component, component set, layer, mode, collection, frame, style, section |
| 디자인 속성 용어 | ✓ | auto layout, layout, padding, gutter, baseline, offset, blend mode, overflow, typography, effect, grid, thumbnail, resampling, color profile, mask, vector, path, clip, miter, bevel, smoothing, paint, class, label, cell |
| 일상화된 외래어 | ✗ (한글) | 페이지, 파일, 링크, 그룹, 텍스트, 이미지, 아이콘, 폰트, 플러그인, 코멘트, 캔버스, 스크롤, 업데이트, 드래그 |
| 고유어·한자어 | ✗ (한글) | 변수, 표, 행, 열, 색상, 모서리, 간격, 정렬, 불투명도 |

- 문장 중간은 소문자(`새 config`, `layer를 선택하세요`), 문자열이 영문 용어로 시작하면 첫 글자만 대문자(`Config 1개`, `Layer 두 개를 선택하세요`).
- 조사는 원래 한글 발음 기준으로 붙인다: `config를`, `preset을`, `layer가`, `mode를`, `token이`.
- 문서(README/CLAUDE.md)의 한국어 본문도 같은 규칙을 따른다.
- **예외: i18n 플러그인**은 사용자가 원래 한국어 문구를 선호해 기존 표기(레이어, 컴포넌트, 모드 …)를 유지한다.
  또한 i18n 플러그인 UI는 variable을 **토큰 / token**, key layer를 **key 레이어**라고 부르고, "이 레이어" 대신 "해당 레이어"를 쓴다.
- **Boolean 값은 `true` / `false`** 로 표기한다 (`참`/`거짓` 금지).

## 구현 패턴

Figma 플러그인은 두 스레드로 나뉘므로 사전도 두 군데에 둔다.

| 위치 | 담당 문자열 | 형태 |
|---|---|---|
| UI (iframe) | 화면에 렌더링되는 모든 문자열, `title=` 툴팁, placeholder, 확인 다이얼로그 | `I18N = { ko: {...}, en: {...} }` + `t(key, ...args)` |
| main (code.js/ts) | `figma.notify`, `figma.closePlugin(메시지)`, UI로 돌려주는 오류/결과 메시지, relaunch 설명 | `MSG`/`STRINGS`/`L` 사전 + 조회 함수 |

- 값이 함수면 보간·복수형 처리: `nTokens: (n) => \`token ${n}개\`` / `` (n) => `${n} token${n === 1 ? '' : 's'}` ``.
  영어식 `plural()`에 단어를 넘기는 방식은 쓰지 않는다 (한국어 어순이 다름).
- 언어 변경 흐름: UI 토글 클릭 → UI 즉시 다시 그림 → main에 `set-lang`/`setLang`/`lang` 메시지 →
  main이 `clientStorage`에 저장하고 이후 메시지를 그 언어로 만든다.
- 시작 흐름: main이 저장된 언어를 읽어 첫 state(또는 `ready` 응답)에 `lang`을 실어 보낸다.
- 새 문자열을 추가할 때는 **ko/en 두 사전 모두**에 넣는다. 한쪽에 없으면 fallback(보통 ko)으로 보인다.
- 한글 입력 IME: 검색창 등 입력 즉시 반응하는 필드는 `compositionstart/compositionend`로 조합 중 입력을 무시한다
  (i18n 플러그인 패턴 참고).

## 플러그인별 현황

| 플러그인 | UI 사전 | main 사전 | 저장 키 | 메시지 타입 |
|---|---|---|---|---|
| Change Marker | `src/i18n.js` `STRINGS` + `t()` | `code.js` `L` | `lang` | `setLang` |
| Dev Inspector | `ui.html` `T`(문구) · `L`(속성 label) · `V`(값) | `code.js` `MSG` + `M()` | `lang` | `set-lang` |
| i18n | `ui.html` `I18N` + `t()` | `code.js` `STRINGS` + `L()` | `language_vars_lang` | `set-lang` |
| Arrow Connect | `src/ui.html` `I18N` + `t()` | `src/code.ts` `MSG` + `M()` | `lang` | `lang` |
| Config Manager | `src/ui.html` `I18N` + `t()` | `src/code.ts` `MSG` + `M()` | `lang` | `setLang` (응답: `lang`) |
| Organize Comp Variants | `src/ui.html` `I18N` + `t()` (오류 패널) | `src/code.ts` `MSG` + `M()` | `lang` | `lang` |
| Organize Sections | `src/ui.html` `I18N` + `t()` (결과·오류 문구 포함) | — (main은 데이터만 보냄) | `lang` | `lang` |
| Sync Icon Colors | — (UI 없음) | 토스트 한국어 고정 | — | — |

저장 키가 플러그인마다 다른 것은 기존 사용자 설정을 보존하기 위해서다 (`clientStorage`는 플러그인별로 분리됨).

## 번역하지 않는 것

캔버스나 Figma 문서에 기록되는 문자열은 **데이터**이므로 번역하지 않는다. 바꾸면 기존 파일과 어긋나거나 코드가 찾지 못한다.

- Arrow Connect: layer 이름 `point-indicator`, `line`, `line-halo`, `line-dotted`, `arrowhead`, `dot-halo`, `dot`, `text`, 고아 표시 `⚠ `, label 기본 내용 `text`
- Config Manager: 표의 `token ID`, component 속성 `Show location` / `Location`, component 설명, 변수 설명, 표 이름 `config-table/…`·템플릿 `config-manager-table-…`, 새 mode 기본값 `Default`·`mode N`
- Change Marker: 코멘트 본문 형식(`변경 ID:` / `Change ID:` label은 UI 언어를 따르되 이전 형식도 인식)
- i18n 플러그인: collection 이름 `language`, CSV 헤더(`1st Section` … `Description`)
- Dev Inspector: 설정값 `ICON_FRAME`, `LANGUAGE_COLLECTION`
- Organize Sections: section 이름 판정 규칙(`building-block`, `pattern`, `.skeleton/`)
- Organize Comp Variants: 브래킷 label(`속성:\n값`), 브래킷 set 이름 `section-indicator`, variant `bracket-direction=…`, 속성 `text`/`show-text`, plugin data 키
- Sync Icon Colors: plugin data 키 `colorSyncExempt`, layer 이름 규칙 `icon-frame`
- 개발자용 `console.log` 문자열 (영어 유지)
- 매니페스트의 relaunch 버튼 이름 (정적이라 번역 불가 — 영어 유지)
