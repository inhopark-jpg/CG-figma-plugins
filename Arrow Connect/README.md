# Arrow Connect

Figma 디자인 파일에서 두 layer를 `point-indicator` style 화살표로 잇고, layer가 움직이면 화살표가 따라가게 하는 플러그인.
주석·플로우 설명용 화살표를 손으로 다시 그릴 필요가 없다.

## 설치

```bash
npm install
```

```bash
npm run build
```

Figma 데스크톱 → Plugins → Development → Import plugin from manifest… → `manifest.json`.

## 사용법

1. 플러그인을 열고, 시작 layer를 클릭한 뒤 끝 layer를 Shift-클릭하고 **연결**.
   새 화살표가 선택된 상태로 만들어져 바로 style을 바꿀 수 있다.
   화살촉은 대상에서 12px(세로 방향은 8px) 앞에서 멈춘다.
2. 화살표를 선택하거나, 화살표가 정확히 하나 붙은 layer를 선택하면 편집할 수 있다. 여러 개가 붙어 있으면 원하는 화살표를 선택한다.
   변경은 즉시 적용된다.
   - **시작 / 끝**: 기본은 자동(서로를 마주 보는 면). 작은 상자의 면을 눌러 고정하거나 **자동**으로 되돌린다.
   - **색상**: preset 8색 또는 사용자 지정 색 (기본 보라 `#8A38F5`).
   - **label 표시**: 화살촉 쪽에 텍스트 표시. label은 대상 layer에서 12px(세로 8px) 떨어지고, 화살촉은 label 앞 12px(8px)에서 멈춘다.
     텍스트는 패널이나 캔버스에서 직접 편집.
   - **⇄ 방향 바꾸기**, **분리**(화살표를 일반 layer로 남기고 추적 중단).
3. 아무것도 선택하지 않았을 때 고른 색은 다음 새 화살표에 쓰인다. 새 화살표는 항상 자동 면·label 없음으로 시작한다.

화살표 구조: `point-indicator` 그룹 = `dot-halo`, `line`(`line-halo`, `line-dotted`, `arrowhead`), `text`, `dot`.

## 패널

- 헤더: 제목, 언어 토글(`한국어 | EN`, 기본 한국어)
- 상황 카드: 선택 안내 / 연결할 두 layer + 연결 버튼 / 선택된 화살표 정보 + 방향 바꾸기·분리
- style section: 시작·끝 면 선택기(편집 중일 때), 색상, label
- 하단: **Live** 표시(클릭으로 일시정지/재개, 추적 중인 화살표 수), **모두 새로고침**
- 창 높이는 내용에 맞춰 자동 조절 (폭 280px 고정)

## 한계

- 화살표는 **패널이 열려 있는 동안(Live)** 만 layer를 따라간다. 닫힌 상태에서 layer를 옮겼다면 플러그인을 다시 열거나,
  화살표를 선택하고 오른쪽 패널의 relaunch 버튼 **Refresh arrows**를 누른다.
- 대상 layer가 삭제된 화살표는 흐리게 바뀌고 이름에 `⚠`가 붙는다. 삭제를 실행 취소하면 복구된다.
- 화살표를 대상 layer와 함께 복제(⌘D, 복사·붙여넣기, Option-드래그)하면 복제된 화살표는 **복제된 layer**에 다시 연결된다.
  화살표와 같은 거리만큼 옮겨진, 이름·종류·크기가 같은 layer를 복제본으로 본다. 한쪽 layer만 함께 복제했으면 그쪽만 복제본에 연결되고
  나머지 끝은 원본에 남는다. 다른 파일로 붙여넣어도 같다. 단, 이 기능이 생기기 전에 복제한 화살표는 원본 위로 겹쳐져 있으므로 다시 연결해야 한다.
- 같은 section 안 layer 사이의 화살표는 그 section 안에 배치되어 section과 함께 움직이고 section 크기 변경에도 유지된다.
- 매니페스트의 relaunch 버튼 이름(`Arrow Connect`, `Refresh arrows`)은 정적 값이라 번역되지 않는다.
  버튼 설명(hover 문구)은 화살표를 만들 때의 언어로 기록된다.

## 파일

| 파일 | 역할 |
|---|---|
| `src/code.ts` | main 스레드: 화살표 생성·재그리기·추적, 선택 처리, 토스트(`MSG`) |
| `src/ui.html` | 패널 UI (공유 디자인 시스템 + 한국어/영어). 빌드 없이 그대로 로드 |
| `dist/code.js` | **생성물** (`npm run build`, esbuild) |
